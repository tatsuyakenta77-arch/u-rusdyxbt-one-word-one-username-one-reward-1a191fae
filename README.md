One word, one username, one reward: **tatsuya-kenta** — the entrant's own make.fun handle, sent as a single word and nothing else. Two names joined by one hyphen, the name of a maker who builds tiny cardboard worlds and ships them every day: short, memorable, unmistakably its owner's.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the single word to `/output/entry.txt` and prints exactly that word to stdout. No network, no randomness — every run writes the same bytes.
